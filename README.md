# PC LAB

한국어 3D 컴퓨터·주변기기·회사 서버 학습 사이트. 정적 파일과 Three.js 0.170.0으로 동작합니다.

## 실행

프로젝트 폴더에서 `python3 -m http.server 4173 --directory dist`를 실행하고 `http://localhost:4173`을 엽니다.

## 기능

- 분해 10단계와 조립 10단계, 단계 이동과 역방향 이동
- 부품 이동 애니메이션, 자동 재생·일시정지 및 속도 선택
- 마우스·터치 회전, 확대, 네 가지 시점, 전체 화면
- 전체 분해도, 부품 라벨, 3D 부품 클릭과 상세 설명
- 반응형 UI, 키보드 조작, WebGL 미지원 안내
- 데스크 셋업 10단계: AC 전원, 모니터, HDMI, USB 키보드·마우스, Ethernet, 부팅, 입력·출력, ping
- 연결/분리 상태에 따른 독립적인 전원·화면·입력·통신 동작, 케이블 연결 애니메이션과 신호 흐름
- 서버 구축 14단계: 랙·디스크·UPS/PDU·PSU A/B·스위치·라우터·KVM·USB/UEFI·Linux·SSH·nginx·UFW·HTTP·백업
- Ubuntu Server 24.04 LTS 개념 설치기: 언어/키보드, DHCP/고정 IP 검증, 가상 스토리지, 사용자/호스트, 공개키 인증 선택
- 가상 터미널: 명시적으로 지원하는 명령만 시뮬레이션하며 실제 명령 실행이나 네트워크 요청은 하지 않음
- PSU, NIC, DNS, UPS 배터리 장애 실습. 같은 LAN과 게이트웨이 경로 및 이름 조회와 IP 접속 구별
- `?lab=pc`, `?lab=desktop`, `?lab=server`로 실험실 바로 열기

## 상태 검증

`node --test tests/systems.test.mjs`

14개 상태 전이 테스트로 케이블 분리, 전원 이중화, 배터리 소진, DNS/IP 요청, LAN/게이트웨이 구분, SSH/UFW 및 백업 동작을 확인합니다.

학습 진행은 현재 페이지 메모리에 유지되며 새로고침하면 초기화됩니다. 모든 장비, IP, 사용자, 명령 응답, 설치 미디어는 가상입니다. 입력한 문장과 실습 설정은 외부로 보내지 않습니다. UPS 유지 시간은 15초로 단축했습니다. RAID와 디스크 파티션은 개념 모델이며 실제 Ubuntu 설치 화면을 그대로 재현하지 않습니다.

실제 조립용 제품 매뉴얼을 대체하지 않는 일반 ATX 학습용 모델입니다. 케이블, 나사, 커넥터의 움직임은 단순화했습니다. 외부 런타임 라이브러리는 `dist/assets`에 포함되어 있으며 폰트 로딩 실패 시 시스템 글꼴을 사용합니다. Three.js 라이선스는 `dist/assets/THREE-LICENSE.txt`에 있습니다.
